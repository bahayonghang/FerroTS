## 3. f_cao 标签表（扩充样本 `data_out.csv`）

- 行数 520,860；时间范围 2023-03-29 14:00 至 2025-05-21 07:59（过程变量从 2023-01-01 开始）。
- 间隔：60 s 占 520,565 次；0 s（重复时间戳）240 次；>1 h 断档 54 处。
- 值：无缺失；min 0.18，p50 0.95，max 6.9；282 个不同值。
- 结构：值变化 8,922 次，恒定段长度 p10/p50/p90 = 60/60/60 min，最长 180 min；值变化集中在整点（8,450 次在第 0 分钟）。结论：每小时 1 个化验值被前向填充到 1 min 网格，真实化验样本约 8.9 千个。
- 重复时间戳的值互相冲突：同一时间戳对应两个不同的 f_cao 值。
- 时间戳的含义（取样时间或结果录入时间）与化验延迟，文件本身无法判定，需用户确认。

## 4. 对计划书第一版数据协议的影响

| 数据事实                      | 计划书现状                                               | 需要的机制                                                        |
| ----------------------------- | -------------------------------------------------------- | ----------------------------------------------------------------- |
| 10 s 采样、6.9 M 行、1 GB CSV | 首版只支持单一宽表，重采样未列入                         | 等间隔网格对齐与聚合（例如 1 min 均值）、解析缓存                 |
| 采样抖动、重复/非递增时间戳   | DataSpec 有“排序与重复策略”                              | 具体重复策略实现 + DatasetReport 计数                             |
| 54% 时间停窑、20 处 >1 h 断档 | 窗口不得跨长停机，但无判定规则                           | 可配置运行状态规则（列 + 阈值 + 最短持续时间）生成段边界          |
| 两列缺失率 9%–13%             | 复现模式缺失值报错                                       | 工程模式受限因果填充 + 掩码，或显式排除列                         |
| 中文列名                      | 未提及                                                   | CSV/TOML/报告/检查点元信息全程 UTF-8                              |
| f_cao 为前向填充的小时化验值  | 第 6.3–6.5 节有 available_at 与掩码损失；软测量变体在 P5 | 去重到化验点、标签掩码、available_at 延迟；软测量前移为独立子任务 |
| f_cao 不在输入变量中          | 第 8.1 节：原版 iTransformer 不能严格复现此任务          | `itransformer_softsensor` 工程变体                                |
