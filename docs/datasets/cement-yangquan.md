## 2. 协议 `cement-twin-v1`

### 2.1 参数

| 参数       | 值                                                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 输入文件   | `data_in.csv`                                                                                                                                                                        |
| 排序与去重 | 按时间稳定排序；重复时间戳保留文件中的第一行                                                                                                                                         |
| 聚合       | 1 min 网格，分钟 = `floor(DateTime, 1 min)`；每个变量取该分钟内有效样本的算术平均                                                                                                    |
| 分钟缺失   | 某变量在该分钟的有效样本少于 3 个时，该变量该分钟缺失                                                                                                                                |
| 运行分钟   | `窑头煤反馈` 的 1 min 均值 > 5；≤ 5 为停窑分钟；`窑头煤反馈` 缺失为缺失分钟                                                                                                          |
| 运行段     | 以运行分钟开始和结束；停窑分钟结束该段；连续缺失分钟 > 5 时结束该段；段长 ≥ 30 min（段长含段内 ≤ 5 min 的缺失）                                                                      |
| 填充       | 只在运行段内，对 18 个变量做因果前向填充，填充值距上一个有值分钟不超过 10 min；不跨段填充                                                                                            |
| 可用分钟   | 在运行段内，且 18 个变量填充后都有值                                                                                                                                                 |
| 窗口       | 起点 o 的输入为 `[o − 96, o)`，目标为 `[o, o + H)`；输入与目标的全部分钟必须可用，并且属于同一运行段内的同一段连续可用分钟；起点步长 1 min                                           |
| 切分       | 整段分配。按时间顺序累计运行段分钟数，段中点位于前 70% 的段为训练，70%–80% 为验证，其余为测试。切分边界因此落在段间隔处                                                              |
| 标准化     | 每个变量独立 z-score；μ 与 σ 只用训练切分的可用分钟计算；σ 为总体标准差                                                                                                              |
| L          | 96 min                                                                                                                                                                               |
| H          | {15, 30, 60} min                                                                                                                                                                     |
| 变量       | 18 进 18 出（`features = M`），列序同文件                                                                                                                                            |
| 时间特征   | `timeF`，`freq = t`，5 个特征 `MinuteOfHour, HourOfDay, DayOfWeek, DayOfMonth, DayOfYear`（TSLib:utils/timefeatures.py:107-113；MinuteOfHour = `minute / 59 − 0.5`，同文件第 45 行） |
| 指标       | 主指标：每个变量的原始单位 MAE 与 RMSE。附加：标准化空间 MSE 与 MAE（全部测试样本 × H × 18 元素等权）。不报告跨变量原始单位混合总分                                                  |
| 验收       | 与基线并列报告，不设门槛（父任务 D3）                                                                                                                                                |

TSLib 引用格式见 `ett.md` 第 1 节。

### 2.2 与任务 PRD 默认值的差异

| 项目     | PRD 默认值                               | 本协议                                     | 理由                                                                                                                                                                                                                                                            |
| -------- | ---------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 填充范围 | 只填充 `窑喂料反馈`、`分解炉内温度1反馈` | 18 个变量都填充                            | 其余 16 个变量在运行段内各有 13 个缺失分钟（原始数据的短断档，均 ≤ 5 min）。不填充时这些分钟会切断可用分钟序列；填充后为 0                                                                                                                                      |
| 缺失处理 | 受限填充 + 掩码                          | 受限填充；填充后仍缺失的分钟不进入任何窗口 | 两列在运行段内的缺失集中在长缺失块：填充后仍缺 19,466 min 与 64,225 min（最长 16,284 min 与 29,037 min），全部位于 2023-03-28 23:11 至 2023-05-13 10:44，属于训练切分。元素级掩码需要改变官方 iTransformer 的输入；窗口级排除只减少训练数据，验证与测试不受影响 |
| 去重     | 未规定                                   | 重复时间戳保留第一行                       | 7 个重复时间戳（14 行）；规则固定后结果可复现                                                                                                                                                                                                                   |
| 切分边界 | 按日期 70/10/20，边界落在段间隔          | 按运行段累计分钟数与段中点分配             | 数据时间范围内有 390.6 h 断档与长期停窑，按运行段分钟数计算的比例与实际训练数据量一致                                                                                                                                                                           |

最少样本数 3、断段 5 min、段长 30 min、陈旧时间 10 min 保持 PRD 默认值。
